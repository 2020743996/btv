# 苹果风格 UI

版本：主界面导航与节目单升级记录。维持既有白色内容底色与操作层级，新增可调透明度的轻量玻璃材质。

## 设计方向

参考苹果的 Liquid Glass 导航层级与清晰度原则，保留 Android 的操作方式、系统字体及现有线性图标，不使用苹果专有组件或字体。

- 内容区保持纯白，正文深灰；蓝色用于操作和焦点，红色用于直播、收藏与危险状态，绿色用于启用开关。
- 玻璃质感只用于导航、节目单工具栏、按钮及播放浮层；边缘高光、柔和阴影和轻量光带叠加在半透明表面上，不实时采样直播画面。
- 透明度范围为 0–40%，默认 18%；不依赖 RenderEffect 或全屏离屏缓冲，API 26 使用同一套轻量绘制回退。
- 圆形图标入口、胶囊按钮、分段选择器使用统一形状；频道列表不再逐行套卡片。
- 点击反馈不改变控件尺寸；电视仍有明确的焦点边框。图标操作提供长按/悬停提示。

## 页面布局

| 页面 | 变化 |
| --- | --- |
| 首页 | 导航包括直播、节目单、收藏、最近观看、频道源、设置；手机左侧展开，电视侧栏常驻，频道列表使用分隔线 |
| 节目单 | 未来七天；电视按频道与时段显示可横向滚动的时间网格，手机按频道与日期显示易滚动的节目行 |
| 平板与电视 | 侧栏外再按分组与内容分栏；手机短屏继续使用可滚动紧凑布局 |
| 设置 | 观看、字号、界面材质、频道源与管理分区；透明度滑块 0–40%，取消/保存仍固定底部 |
| 频道管理 | 源地址、失效线路、日志统一为图标 + 标题 + 右箭头的导航行 |
| 地址编辑 | 保留状态机和固定操作区，仅统一输入框、列表分隔线及圆润按钮；短横屏键盘适配不变 |
| 搜索 | 输入框与历史项统一材质，结果列表使用分隔线 |
| 播放 | 浅色高可读性信息层，频道和节目为主，线路状态单列；频道面板统一蓝色选中态 |

大圆角仅用于导航控件、输入工具、播放浮层，作为本次苹果风格的统一规则；普通内容不加浮动面板。操作顺序和位置继续遵循原一致性约束。

## 代码范围

- `AppleUi.kt`：材质、圆角、分隔线、分区标题及导航行。
- `UiActions.kt`、`UiComponents.kt`：复用动作组件、按压反馈、提示与标题栏。
- `Theme.kt`、系统主题：统一白色页面和系统栏，播放器保留深色沉浸环境。
- 页面组件仅修改布局与视觉；不改下载、测速、分辨率排序、缓存和播放切线逻辑。

## 验证范围

自动化覆盖颜色对比度、宽手机横屏布局，以及首页导航/选台/收藏/切分组、设置大字体、管理入口、播放频道面板和地址编辑流程。

本次更新完成 Debug APK 构建、62 项 JVM 单元测试及 Android 15 phone35 模拟器 24 项 UI 测试；主 UI 的 5 项横屏测试通过，两项电视专属测试在手机模拟器上按条件跳过。Android TV 实机、MT9653 并行播放性能及 API 26 真机视觉仍未验证；不能以模拟器结果代替雷鸟鹤6 26款实测。
