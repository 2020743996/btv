# 苹果风格 UI

版本：主界面导航与节目单升级记录。维持既有白色内容底色与操作层级，导航使用固定上游版本 LiquidGlass 材质。

## 设计方向

参考苹果的 Liquid Glass 导航层级与清晰度原则，保留 Android 的操作方式、系统字体及现有线性图标，不使用苹果专有组件或字体。

- 内容区保持纯白，正文深灰；蓝色用于操作和焦点，红色用于直播、收藏与危险状态，绿色用于启用开关。
- 手机底部导航和电视侧栏使用 LiquidGlass AGSL 材质：API 33+ 折射着色器，API 31–32 模糊，API 26–30 半透明 scrim；导航独立叠在内容之上，内容区预留空间。
- 透明度范围为 0–40%，默认 18%；玻璃只采样首页静态 UI chrome，不覆盖或采样直播视频。MT9653 为 Android TV 性能验收基准，不按芯片型号拦截设备。
- 工具栏控件、频道行、导航行和弹窗选项使用中圆角；只有频道分组与日期筛选使用胶囊形。频道列表不再逐行套卡片。
- 点击反馈不改变控件尺寸；电视仍有明确的焦点边框。图标操作提供长按/悬停提示。
- 全局页面边距使用紧凑 16dp、常规 24dp；普通控件圆角 12dp、输入框 14dp、浮层 20dp。交互控件保持至少 44dp 的主要触控尺寸。

## 页面布局

| 页面 | 变化 |
| --- | --- |
| 首页 | 手机底部与电视侧栏仅保留节目单、设置；全部/收藏/最近/源分组筛选合并到节目单页，不再重复展示直播入口或继续观看置顶卡片 |
| 节目单 | 保留未来七天，并按有效回看源的声明范围显示历史日期；手机与电视按频道显示节目摘要，展开单一频道查看所选日期；电视支持遥控器聚焦展开 |
| 平板与电视 | 保留常驻主导航侧栏，频道类别切换改为内容区横向筛选；手机短屏使用滚动列表与固定底部导航 |
| 设置 | 观看、字号、界面材质、频道源与管理分区；透明度滑块 0–40%，取消/保存仍固定底部 |
| 频道管理 | 源地址、失效线路、日志统一为图标 + 标题 + 右箭头的导航行 |
| 地址编辑 | 保留状态机和固定操作区，仅统一输入框、列表分隔线及圆润按钮；短横屏键盘适配不变 |
| 搜索 | 输入框与历史项统一材质，结果列表使用分隔线 |
| 播放 | 浅色高可读性信息层，频道和节目为主，线路状态单列；频道面板统一蓝色选中态 |

普通内容保持平面列表和分隔线；不以卡片包裹每一行。操作顺序和位置继续遵循原一致性约束。

## 代码范围

- `AppleUi.kt`：材质、圆角、分隔线、分区标题及导航行。
- `UiActions.kt`、`UiComponents.kt`：复用动作组件、按压反馈、提示与标题栏。
- `Theme.kt`、系统主题：统一白色页面和系统栏，播放器保留深色沉浸环境。
- 页面组件仅修改布局与视觉；不改下载、测速、分辨率排序、缓存和播放切线逻辑。

## 验证范围

自动化覆盖颜色对比度、宽手机横屏布局，以及首页底部/侧栏导航、频道筛选/收藏、无历史状态、历史节目回看、设置大字体、管理入口、播放频道面板和地址编辑流程；首页不提供录像、录制入口。

2026-09-27 的本轮验证：65 项 JVM 单元测试通过、Lint 0 错误；Android 15 phone35 上 32 项仪器测试通过，3 项 TV 专属测试按设备条件跳过。仪器测试生成了布局截图，但未逐张人工检查。LiquidGlass 上游来源、固定提交和本地构建调整见 [第三方来源说明](../third_party/liquidglass/UPSTREAM.md)。MT9653 并行播放性能及 API 26 真机视觉仍须在实机验证；不能以模拟器结果代替雷鸟鹤6 26款实测。
