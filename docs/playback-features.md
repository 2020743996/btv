# 播放功能预览

版本：1.12.0-preview.1 已作为 GitHub 预览版发布；当前 `main` 在其基础上增加了更直接的选台入口、首页节目单及源管理流程。这些后续改动尚未另行发布。

## 功能补齐范围

现有功能包括多个 M3U、收藏、最近观看、搜索、自动备用线路和当前/下一节目。
本次补齐日常观看中不依赖额外服务的控制能力：手动线路、画面模式、音轨字幕、睡眠定时、频道节目列表，以及手机播放中的直接选台入口。

参考 [TiviMate 官方功能列表](https://play.google.com/store/apps/details?id=ar.tvplayer.tv) 的节目单、多源、回看、录制等分类，结合 btv 同时面向触摸屏与电视遥控器的定位选择本次范围。音轨控制使用 [Media3 官方轨道选择 API](https://developer.android.com/media/media3/exoplayer/track-selection)。

## 操作流

此前：播放失败依赖自动换线；画面模式固定；只能看当前/下一节目；手机播放中缺少明确的选台入口。

现在：

1. 播放页右上“频道”直接打开选台面板；“播放选项”、遥控器菜单键或方向右键打开控制菜单。
2. 进入线路、画面、音轨、字幕、定时或节目单子页，设置立即生效。
3. 返回按钮或系统返回回到菜单；“关闭”始终直接回到播放。
4. 选择线路后自动关闭菜单并开始连接；菜单内的“切换频道”仍可呼出选台浮层。

## 页面状态

菜单：关闭 → 主菜单 → 子页；子页返回主菜单，关闭操作回到播放。菜单显示期间不触发 Activity 的上下换台拦截。节目列表可聚焦滚动，不把尚未播出的节目伪装成可点播内容。

播放：连接 → 正在播放 / 缓冲 → 超时或错误 → 下一未失败线路 → 全部失败。手动选线重新开始一轮尝试，不增加当前线路失败计数；失败集合按 URL 去重，遍历完毕后停止，不无限循环。原有稳定播放确认规则保留。

睡眠：关闭 → 已设定 → 修改 / 取消 / 到期。使用单调时钟截止时间，避免修改系统时间影响倒计时；换台不会重置。到期暂停并退出播放页，不会关闭电视电源。退到后台时播放器暂停，返回前检查是否到期；退出播放页后定时器随页面销毁，不安排系统闹钟。

## 数据与支持边界

- 画面模式保存在本地设置，三种模式分别保持原比例、等比裁切、不等比拉伸。
- 手动音轨选择仅针对当前媒体；换线/换台清除轨道覆盖。字幕关闭在当前播放会话中保留，不会自动跨会话记忆具体轨道。
- 音轨和字幕需直播源实际提供，不支持烧录字幕的开关、字幕下载或实时翻译。
- 线路画质优先显示播放器已测量的结果，否则显示既有源提示；没有数据就不虚构分辨率，不展示可能带有账号令牌的完整播放地址。
- 节目单合并 M3U 声明与独立设置的 XMLTV 地址。首页有全频道当前/下一节目视图；播放菜单显示当前频道未来 24 小时内的节目，并非可点播或网格指南。没有匹配数据时显示空状态。
- 回看需源的 catch-up 协议/授权；录制需存储、后台任务和配额管理；多画面需设备解码能力。这些功能以及 Xtream/Stalker 登录尚未实现。

## 组件

- `PlaybackMenu`：统一页面路由与轨道订阅。
- `PlaybackOptionsDialog`：复用 `PageHeader` / `DialogFooter`，中间内容滚动，固定操作区。
- `PlaybackOptionRow`：选择行、导航行共用间距和单一焦点，单选状态在右侧；节目行只读且可聚焦。
- `PlaybackOptions`：可独立测试的线路遍历、定时器、画面模式规则。

## 验证边界

2026-09-20：56 项单元测试通过；Android 15 模拟器 16 项完整交互测试在横竖屏各通过一次，最终菜单修正另以 6 项测试在两种方向各复测通过。构建成功、APK v2 签名有效，Lint 0 错误、8 项依赖/资源提示。

覆盖纯逻辑单元测试和 Android 模拟器横竖屏交互测试，包括特大字体、长列表、选线回调、即时画面/定时设置、空状态、遥控器确认和真实 ExoPlayer 本地音轨解析。模拟器与本地音轨测试不能替代真实电视设备、多个现场直播源、弱网和长时间播放验证。
