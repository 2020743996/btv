# 操作流与状态设计

## 操作流

- 首次使用：首页无源提示 → 管理频道源 → 底部“添加” → 输入地址 → 底部“添加”或键盘完成 → 立即保存并加载该源 → 返回首页。
- 日常启动：手机显示频道列表，电视续播最近频道；设置可选“按设备／直接播放／频道列表”。
- 导航：手机底部与电视侧栏统一为“节目单、设置”。频道、收藏、最近观看及源分组作为节目单页快捷筛选；频道源管理从设置进入，刷新和测速位于右上“更多”。旧版保存的“直播”导航状态升级后归一到节目单。
- 首页：节目单页按顶部、快捷筛选、频道节目摘要组织；不再重复展示独立直播入口或继续观看置顶卡片。没有 EPG 的频道仍留在列表中，可直接播放；收藏和最近观看筛选为空时显示明确空状态，不展示录像/录制入口。
- 播放：右上“频道”直接开选台面板，“播放选项”位于其左侧。面板关闭按钮、空白处、系统返回手势和遥控器返回都先关闭面板；电视方向左仍可打开。
- 源异常：各源独立加载。失败时优先使用七天内该源最近一次成功数据并显示状态；用户可从源列表重试。全部失败且无旧数据时直接显示“重试／管理频道源”。
- 节目单：合并 M3U 声明的 XMLTV 与设置中的独立地址；保留未来七天，并按频道有效 `catchup-days` 扩展历史日期。手机与电视默认按频道显示节目摘要，同一时间仅展开一个频道；切换日期会收起展开项。当前节目进入直播，未来节目显示详情，历史节目只有在该频道具备有效 M3U 回看模板时才进入回看。无 `catchup-days` 的源不开放历史播放；单个 EPG 源失败时保留其最近成功数据。
- 备份：系统文件选择器导出版本化 JSON；导入先校验再确认，确认后一次性替换配置。导出提示文件可能包含源地址凭据。

## 页面状态

| 页面 | 状态与转移 |
| --- | --- |
| 源列表 | 已保存列表 → 添加／编辑草稿；删除确认后立即保存；单源显示正常、旧数据或失败，异常状态可重试。 |
| 源输入 | 不合法或重复则保留草稿并说明错误；合法提交立即保存并回列表；取消已修改草稿需确认。 |
| 首页 | 加载中 → 节目单、设置、无源引导或失败操作；节目单筛选支持全部、收藏、最近和源分组，导航切换保留筛选与节目日期。 |
| 播放页 | 播放 → 选台面板或播放选项；关闭面板恢复“频道”入口焦点，返回不退出播放；无面板时返回首页。 |
| 设置 | 启动方式、字体、老人模式与独立 EPG 地址在底部统一保存；源管理可直达，备份导入需确认。 |

## 组件与一致性

- `PageHeader` 保持返回在左上，页面操作在右上；`FormActions` 保持取消在左、主操作在右；确认弹窗复用 `DialogFooter`，行编辑与删除复用 `TableActions`。
- 主导航在手机和电视保持相同层级；手机固定底部导航，电视侧栏常驻；节目单筛选条在两种设备共用，电视保留明显遥控器焦点。频道摘要行可由触摸或确认键展开/收起，回看操作只对可用历史节目出现。
- 手机底部导航与电视侧栏使用 LiquidGlass；内容为其独立 backdrop，安全区不重叠。API 33+ 使用折射着色器，API 31–32 使用模糊，API 26–30 使用半透明 scrim；播放器视频层不参与采样。MT9653 是 TV 性能基准，不按型号建立白名单。
- 源列表仅保留底部右侧“添加”，输入页底部为“取消／添加（或确定）”。短屏键盘上方固定提交区，大字号不挤走按钮。
- 首页搜索保持可见；刷新、测速收在“更多”，频道源管理从设置进入；手机横屏及平板按可用宽高适配，避免底栏与频道内容重叠。
- 源与 EPG 的成功快照按地址独立存于应用私有目录，最多保留七天；部分失败不把整批标记为已刷新。页面可见期间每分钟重试异常频道源，也可手动重试。

## 验证

- 本轮 btv 与 LiquidGlass 共 85 项 JVM 测试通过，Android 15 phone35 上 30 项仪器用例中 28 项通过、2 项电视专属测试按设备条件跳过；Lint、Debug 验证与正式 APK 构建通过。上游 Robolectric smoke 测试需要在线下载 Android SDK 镜像，且当前镜像校验和失败，已从集成测试任务排除。
- Lint 对 LiquidGlass 上游稳定图形上下文生命周期访问关闭了单项 Compose detector；项目本身仍有依赖版本与既有资源提示，无新增应用侧 lint 错误。
- MT9653 实机帧率、遥控器焦点与播放并行性能尚待雷鸟鹤6 26款实机验证。真实多源直播与长时间弱网播放仍需设备和有效源验证。
- 2026-09-16 的旧版曾通过 48 项单元测试与 12 次手机横竖屏交互测试；那次测试对应“添加后再保存”的旧流程，不作为本轮结果。
