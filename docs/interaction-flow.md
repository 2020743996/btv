# 操作流与状态设计

## 现状操作流

- M3U 地址：列表 → 添加/修改 → 临时列表 → 保存。临时修改无明确标识，旋转重建丢失草稿，系统返回直接退出。
- 首页：刷新、测速独立写缓存，旧任务可能覆盖新源；M3U 解析仍占用主线程。
- 播放：测速只保留前三条高分辨率源，较低清晰度的可用备用线被排除；推测画质覆盖实测。
- EPG：仅重新下载 M3U 时触发下载，定时刷新只是查询已有节目。

## 新操作流

- 保留用户指定的列表底部添加入口，添加位于保存左侧；表单始终以取消在左、提交在右。
- 点击添加 → 输入 → 校验格式/重复地址 → 返回标为未保存的列表 → 保存并返回首页。
- 输入不合法时保留草稿并显示具体错误；保存空列表仍有效，意味着清空所有源。
- 系统返回和标题返回行为一致：表单无修改直接返回列表，有修改先确认；列表有修改则确认后才退出。
- 删除先确认。旋转/系统重建恢复列表、编辑目标、草稿和确认状态。
- 刷新开始即取消测速；更换源使缓存版本失效；任务只能向其开始时的版本写入。
- 网络请求取消会终止底层连接，下载和测速有总时间上限。
- 可用线路全部保留，高分辨率优先但仍能回退到流畅的低分辨率线。
- EPG 在首页和播放页可见期间检查过期并真正下载；源改变清空不匹配的节目单。

## 页面状态机

| 页面/状态 | 事件 | 后续状态 |
| --- | --- | --- |
| 地址列表：已保存/未保存 | 添加、编辑 | 编辑草稿 |
| 编辑草稿 | 提交不合法或重复 URL | 编辑错误，保留输入 |
| 编辑草稿 | 提交合法 URL | 未保存列表 |
| 编辑草稿 | 返回/取消 | 无变更回列表，有变更显示放弃确认 |
| 地址列表 | 返回 | 已保存则退出，未保存则显示放弃确认 |
| 地址列表 | 删除 | 删除确认 → 未保存列表 |
| 地址列表 | 保存 | 持久化 → 缓存失效 → 首页重新加载 |
| 首页：可用 | 测速 | 检测中，可取消 |
| 首页：检测中 | 刷新/更换源/取消 | 废弃检测结果；刷新时重新加载 |
| 首页：加载中 | 成功/失败 | 可用、旧缓存提示或错误重试 |

## 组件改动

- `AddressEditorState` 管理可保存的页面状态及校验、提交、放弃和删除转换。
- `PageHeader` 显示已保存/未保存状态；返回固定在左侧。
- `FormActions` 固定在表单底部，输入区含标题可滚动，键盘和短屏不挤走提交区。
- 键盘弹出后可用高度不足 220dp 时，暂时隐藏表单标题、使用无浮动标签输入框并收紧上下间距，避免大字体输入框裁切；底部取消/提交的位置不变，取消仍可返回。键盘收起后恢复完整标题。这是针对短屏输入的适配，不改变操作层级。
- `DialogFooter` 承担放弃/删除确认；`TableActions` 继续位于地址行最右侧。
- `ActionButton` 移除重复焦点节点，保留标准点击节点的遥控器与触摸行为。
- 首页测速入口在检测中切换为取消操作，取消后保留原列表。

## 代码修改

| 范围 | 实现 |
| --- | --- |
| 地址操作流 | `AddressEditorState.kt` 的纯状态转换与 URL 校验；`AddressEditor.kt` 保存状态、共用返回逻辑及固定底栏 |
| 操作一致性 | `UiActions.kt`、`UiComponents.kt` 统一焦点和输入框功能色；相关页面复用 |
| 下载与测速 | `NetworkCall.kt` 取消底层请求；`MainActivity.kt` 管理任务与源版本；`LineTester.kt` 保留所有可用线 |
| 播放画质 | `M3uParser.kt` 区分实测与提示，拒绝旧版本写入；`StreamResolution.kt` 排序采用实测优先 |
| 播放健康 | `PlayerActivity.kt` 暂停不计稳定时间，媒体连接不受下载总时限影响 |
| 节目单 | `EpgParser.kt` 缓存源隔离、后台解析和互斥刷新；首页/播放页按可见生命周期触发 |

短屏校验失败时收起键盘展示错误，保留输入，用户可重新点选输入框继续修改。

## 验证结果（2026-09-16）

- 48 项单元测试通过：地址状态、旧测速写入拒绝、请求取消/超时、低清备用线、实测画质纠错、EPG 源变更等。
- Android 15 手机模拟器：6 项交互测试在竖屏和横屏分别通过，共 12 次；包括真实系统键盘、1.5 倍字体、触屏提交、确认键、错误反馈、草稿保存状态恢复和放弃确认。
- 横屏已核对系统截图：输入框与取消/添加完整显示，无重叠。设备测试显式断言方向，保存恢复采用 StateRestorationTester 模拟系统重建，不等同于真实进程死亡测试。
- `testDebugUnitTest lintDebug assembleRelease` 成功；Lint 无错误，9 项依赖/资源提示。APK v2 签名校验通过。
- 未验证真实电视遥控器、真实源长时间播放和设备弱网；模拟器测试不替代这些场景。
